## Findings to decide on

1. **Fonts — resolved.** "Outfit"/"Syne" were named but never loaded, so each machine
   laid the app out in its own fallback. Both are now bundled (`frontend/fonts/`, OFL 1.1,
   ~96 KB, self-hosted). With the real fonts the wordmark steps down below 1280px.
   `verify-ui` 292/292 including both font-loaded checks (was 287/290 on the Inter fallback).
   Before/after: `screenshots/night6g/`. **On the laptop, look at it once** — everyone who
   had Segoe UI will now see Outfit/Syne.
2. **`verify-ui` / `verify-editor` / `verify-audio` assume Laravel.** They're in
   `verify:desktop`, not `verify:web`. The static build's equivalents are `verify-static`
   and the static branch of `verify-projects`.
3. **Locale.** Chromium can't open UTF-8 file paths under the C locale. `verify-suite`
   sets `LANG=C.UTF-8` when unset; run the tools directly with a UTF-8 locale.
